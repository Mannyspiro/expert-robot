# CairoSVG renderer compatibility · November 20, 2026

CairoSVG 2.8.2 is the Merlin wiring requirements pin at expert-robot draft 584b948332b76596311d75133c0430d761e2f67a. The current 2.9.1 stable release was published September 7, 2026, and is recorded at tag commit 3b7a250c9e955db9c3cdf525d5b5027a9a396201 under LGPL-3.0. The 2.8.2 tag resolves to 9e8c6ede00dd1c4495fca4809b4cabd628a85eb9 under the same license. The newer wheel SHA-256 is f91c5628e834be024a0ed4544d76261cd84016a4c73bcdf26c386495825c05a1. All 18 installed CairoSVG package files matched the exact published source tree. Resolved wheel digests for the two local arms are in dependencies.json.

Official 2.9.0 release notes bound recursive SVG use expansion and drop Python 3.9 support. The 2.9.1 advisory reports reduced path parsing work. Reviewed source reconstructs a bounded SVG from the typed wiring model before rasterizing. Input from a local guide folder is compared with the reconstruction. The trials used only ordinary source-generated SVG. No advisory input or external target was exercised.

Both 2.8.2 and 2.9.1 passed the nine existing local drafting tests on Python 3.12.14. Within-version replay accepted the benign lab diagram on both versions. The guide PNGs for that case are byte-identical. CairoSVG 2.9.1 still refused the archived 2.8.2 control package because it records renderer version in the exact binding. The refusal produced no review receipt. Thus new guide generation works on the tested platform, but a pin-only update would break replay of the older guide. The CACE Python 3.9 workflow did not run CairoSVG in this review.

To reproduce, use the tagged project snapshot and separate Python package overlay paths from dependencies.json. Run the project's nine drafting tests with each path. Run probe.py with --create on distinct guide and result folders under each version. Then run it with 2.9.1 against the existing 2.8.2 guide, omitting --create and providing a fresh result folder. No live pin change was made.
