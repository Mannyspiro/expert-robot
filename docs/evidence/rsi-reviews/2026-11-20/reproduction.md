# Reproduce the registered schematic trial

The input sheet, expected decisions and fixture transformations are frozen in eval/holdout.json (SHA-256 bb987660af2d3f28a041eb56c7abb1a9c14003553c4df3aabb5ed30d4f88eb4b). D0 uses the repository lab sheet. H1 through H4 use a different branched source, with predeclared raster changes. The evaluation was independent inside the same team. It used deliberately all-pass supplied verdicts across all arms. A positive accepts. A refusal or an abstention that blocks acceptance withholds. Invalid-image acceptance with an advisory warning would fail.

The baseline snapshot is Expert Robot draft commit 584b948332b76596311d75133c0430d761e2f67a. Its drafting control git blob is 0fc229b3669f1fb5303d7ecae44774c00af72c0e. Put that checkout at baseline next to eval. Apply each patch separately to another checkout of the exact baseline. Run eval/runner.py with the candidate checkout and the explicit flags in its evaluation JSON. To compare all runs, place them as baseline.json, arm_a.json and arm_b.json under eval and run eval/compare.py. Its parity check compares exact source and PNG hashes across all arms. The synthetic tests use a fixed renderer. Re-evaluating with another renderer changes what was sampled.

Use the current dot sources pinned in reviewer-sha256.txt for run_dot_review.py. The historical replay separately uses its earlier pinned source in dot-replay.json. That runner scores measured labels from the independent fixture executor via the original CrossAgentReviewer. It passes only frozen IDs, source hashes and fixed proposals to the supplied review adapters. No agent proposal code is executed by dot. assess.py and ideonomy.py use Merlin scientific_loop.py at git blob 43a69eb8891f96d65a815e0f091c2df505fa64e6.
