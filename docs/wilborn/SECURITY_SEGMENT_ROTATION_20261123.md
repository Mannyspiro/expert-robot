## Boundaries
Staging is not continuous service rotation: an operator must quiesce the predecessor, preserve/archive unresolved alerts and explicitly review service handover and single-writer ownership. This API checks a staged candidate against fresh anchors and the untouched genesis; it is not an historical multi-segment viewer or deployment approval. The active source, archive, custody and keys remain host-managed. Fresh anchor renewal, independent key custody, production retention horizon and approved isolated OCI/private-host validation remain open. The measured full-capacity cost may support earlier rotation, but production threshold depends on actual event rate, operator response time and host performance.
