# OCI native Chromium and actual Merlin Studio UI — 2026-11-22

## Accepted, reproducible observations

The existing ARM64 OCI host has root-owned, executable Chromium Headless **156.0.8078.79** at `/usr/lib64/chromium-browser/headless_shell` (SHA-256 `22870374b6f2acfa00ac7c54a09eb30aacb1cdac932aba97e654e3dff458318f`). The browser inventory [run 45015038714](https://github.com/morganaspim/Cace-app/actions/runs/45015038714) also observed Bubblewrap and available unprivileged user namespaces; no browser was installed.

The first no-network browser fixture [run 45015164392](https://github.com/morganaspim/Cace-app/actions/runs/45015164392) executed JavaScript and emitted PNG but mixed Chromium stderr into the purported HTML evidence. The corrected isolated browser fixture [run 45015260267](https://github.com/morganaspim/Cace-app/actions/runs/45015260267) passed with separate HTML and stderr; JavaScript changed the page DOM and the browser produced a PNG without `--no-sandbox`.

The actual product interface was then tested in [run 45015468598](https://github.com/morganaspim/Cace-app/actions/runs/45015468598), artifact `14751731148`. The page was fetched directly from product revision `d2c53ebce82e918ac5a246c8ef9416abc47032a1`, path `portable/merlin_studio/web/index.html`, SHA-256 `c8139e25334f5924b48f460f60b5b0ec3934bd0ab293f60c91e6a70b2e210134` (73,060 bytes), unchanged from its pinned Git blob `a8831fc99fc488eaad4a360fa4cdc30aa0123c15`. Chromium rendered the **1200 × 800** interface screenshot (SHA-256 `487d5bfd5037f902bc6c125cb8f2c32ad266f4bbb0ed6d6d0dd9d16129f58ff3`), observed the welcome heading, composer and message textarea, and actually executed client JavaScript (Linux `Ctrl K` shortcut). The no-network namespace was intact; no real model, remote account, production service, software installation, or privilege modification was used. The UI correctly displayed a **disconnected local server** because that run intentionally did not start the backend. This is renderer/client JavaScript acceptance, not working chat or a browser-agent capability.

## Explicitly negative host result, not a reason to weaken a gate

An attempt to launch temporary Studio HTTP and Chromium together inside the rootless network namespace [run 45015957524](https://github.com/morganaspim/Cace-app/actions/runs/45015957524) passed the same **112/112** native product cases but stopped in a separate browser phase: UID 1000 could not bring up `lo` (`PermissionError: [Errno 1] Operation not permitted`). The native staging, source-package verification and cleanup still passed. The first assembly attempt [run 45015906990](https://github.com/morganaspim/Cace-app/actions/runs/45015906990) had stopped earlier during admission because a function was called before its definition. Both failures remain in Actions history, unmodified.

An independent no-mutation diagnostic [run 45016245288](https://github.com/morganaspim/Cace-app/actions/runs/45016245288) showed that within the current-user user+network namespace, AF_INET loopback without interface administration returns Linux `ENETUNREACH` (errno 101). This is a measured host isolation limitation, **not** a Studio application error. Do not disable Chromium sandboxing or call the stricter network-isolation gate complete.

A separately scoped, **limited host-loopback** UI acceptance was prepared: it uses temporary `127.0.0.1:18771`, disables Merlin's optional network/Python/desktop tools in disposable state, and leaves external network isolation explicitly unverified. It does not substitute for the original production sandbox gate; preserve its independent run evidence before changing status.

## Remaining release gates

Real-model responses, root-bound model/provider identity and two-request acceptance, actual browser-agent tool automation, hostile-page containment, full OS sandbox controls, desktop approvals, product license review, startup/reboot/off-host restore, and final signed release are open. The model provider's privileged verifier earlier stopped because `/usr/bin/sudo` is root-owned mode `04111` and cannot be hashed by UID 1000; this is tracked separately from Chromium and public HTTPS research tests.

Scientific framing: observation=real OCI browser render and native test output; abduction=loopback interface control explains connected-browser failure; falsifier=successful namespace-private AF_INET connection or independently verified alternate isolation; next discrimination=limited localhost GUI receipt and reviewed sandbox alternative. N-ality tracks source identity, model capability, network isolation, authority and lifecycle independently. Simplex and fuzzy scores are **not applicable** to these Boolean acceptance gates. Canonical Merlin production master v6 remains unchanged.
