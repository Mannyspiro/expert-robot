# Private release scope and remaining work

The accepted result is the selected private Merlin runtime release, supported by the existing source, native, research, validation, deployment and inspection runs linked in the [release note](PRIVATE_RESEARCH_RELEASE_20261121.md).

## Remaining acceptance gates

- **Remote user access:** configure the actual trusted issuer/introspection endpoint, resource/audience, allowed subjects/read scope and publishing route; test an actual authorized caller.
- **Operational recovery:** coordinated recovery of the selected stores, off-host custody and a retrieved restore, sustained capacity and fault telemetry require their own observations. Retaining research evidence alone does not establish a full production backup/restore.
- **Complete two-coder improvement cycle:** the two actual generation attempts remain incomplete. A further episode requires an explicitly admitted budget and unchanged failure history. A's identity with the baseline provides no improvement claim.
- **General execution and independent verification:** broader Hermes/MCFC routes and genuine independent CACE/formal verification retain their own contracts and evidence.
- **Broader applications and research:** native CAD/wiring/simulation, HUD/Forge/voice/Learning, context/retrieval, model efficiency and advanced research retain the original master-plan acceptance criteria.
