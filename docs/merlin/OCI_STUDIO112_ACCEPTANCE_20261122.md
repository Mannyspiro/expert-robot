No real model inference, fetched Internet episode, Avrea work, ChatGPT account/site access, external model spend, system installation, service mutation, merge, deployment or formal promotion occurred in these CI gates.

3. **User-ready packaging:** validate offline archive extraction, UI rendering with a real graphical browser, exact model setup, restart recovery, platform limitations, and end-user access without unreviewed external tools.
4. **Release review:** reconcile the two draft PRs, canonical registry, remaining production security gates and plan coverage. Keep unverified modules and missing evidence explicitly open.

**Research discipline:** Preserve original failures and exact hashes; a test count is not a calibrated intelligence score. Potential confounding from OCI code-root permissions is documented; source fix is supported by a discriminating writable-workspace regression but does not prove elimination of all other subprocess hazards.
