## Scope boundaries and competing evidence

- The three messages were entered using the real authenticated HTTP API; the browser **rendered** the saved conversation after restart. This did **not** test typing/clicking those three messages through GUI controls, agent-driven browsing, or real language-model inference. The Python test fixture and a public CPython source research cycle are not a model-quality evaluation.
- The browser connected on **host-loopback**, not within a kernel-isolated network namespace. The earlier strict combined gate [#45015957524](https://github.com/morganaspim/Cace-app/actions/runs/45015957524) failed to bring up `lo` (`EPERM`), and independent [#45016245288](https://github.com/morganaspim/Cace-app/actions/runs/45016245288) observed `ENETUNREACH` errno 101. A browser proxy flag and disabled Merlin network tool are not proof of host egress containment. **Full network isolation remains OPEN.**
- The existing local model endpoint passed a limited zero-generation transport check [#45013999132](https://github.com/morganaspim/Cace-app/actions/runs/45013999132), but the required privileged process attestation is blocked because the root-owned `/usr/bin/sudo` binary is mode `04111` and unprivileged UID1000 cannot read it for SHA-256 verification [#45013838951](https://github.com/morganaspim/Cace-app/actions/runs/45013838951). No permission weakening or unverified provider trust was applied; **actual two-generation model acceptance remains OPEN.**
- Full production offline packaging requires legally reviewed model assets and per-platform Python/model runtime distribution, independent recovery/reboot testing, least-privilege browser and desktop tools, and reconciled source/release PRs.
