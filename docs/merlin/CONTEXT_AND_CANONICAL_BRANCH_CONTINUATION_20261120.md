The host must supply a validated source-bound research frame, provisioned project, principal, executor identity/digest, strict current approval/lease checks and cancellation.

A Hermes adapter returns the existing canonical snapshot ArtifactRef through the actual research handler and its existing evidence recorder, hypothesis ledger and graph. Missing CACE credentials remain blocked_missing_credentials; hypothesis status is not promoted.

The final boundary review added strict rejection of reserved path components, a cancellation/authorization check after intent publication and before dispatch, and a snapshot precondition preventing an intervening tick from attaching mismatched state. This is cooperative trusted in-process code, not process isolation, a live provider, full outbox/worker deployment or exactly-once external effects. Ambiguous effects still require a separately designed trusted reconciliation route.
