# CACE Mathematical Puzzle Boxes

Puzzle Boxes are generated research objects designed to make CACE **discover**
mathematics rather than merely consume known formulas.

A box exposes a problem but seals the construction mechanism until the
conjecture/proof attempt is frozen.

Pipeline:

```
generate box
-> expose objects/constraints/observables only
-> Expert Robot proposes invariant/obstruction/equivalence
-> counterexample search
-> freeze conjecture
-> reveal sealed witnesses for evaluation
-> formalize in Lean
-> prove/refute
-> benchmark any derived optimization
-> feed proved useful mathematics back into CACE
```

Initial families:

- symmetry orbits;
- boundary/topology mutations;
- dualities/involutions;
- exact scaling collapses;
- spectral collisions/counterexamples;
- discrete-to-continuum convergence;
- metamaterial unit-cell equivalence;
- certification-gap problems;
- historical-geometry controls separating geometry from symbol assignment.

Puzzle Boxes are useful even when they fail: a refuted conjecture becomes a
stored counterexample and helps improve future theorem search.

## Connection to the Research Object Foundry

The NASA-inspired Research Object Foundry generates **physical/design**
candidates; Puzzle Boxes generate **mathematical research pressure**.

They connect as:

```
generated 3D object / metamaterial / CRL experiment
-> simulation data
-> derive Puzzle Box
-> discover mathematics
-> Lean proof
-> verified optimization
-> faster/better object search
```

The goal is a closed verified discovery loop rather than unconstrained
self-modification.
