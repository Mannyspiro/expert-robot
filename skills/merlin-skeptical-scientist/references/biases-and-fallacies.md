# Contextual bias and argument checks

Use this conditional map, not a diagnosis or universal questionnaire. Record possible mechanism, observed trigger, decision at risk, countermeasure and result/unknown.

| Mechanism | Trigger | Countermeasure |
| --- | --- | --- |
| Confirmation/motivated reasoning | Only supportive runs or sources | Predeclare falsifier; seek strongest concrete counterexample |
| Anchoring | First model/number dominates | Save independent initial frame; recompute from inputs |
| Availability/salience | Vivid anecdote replaces sampling | Inspect denominators, coverage and comparable cases |
| Authority/bandwagon | Status replaces relevant method | Inspect evidence/scope; use expertise without treating it as proof |
| Selection/survivorship/reporting | Missing failures/nonresponses/nulls | Preserve attempt ledger and selection rules; state missing populations |
| Confounding | Multiple inputs differ | Matched controls, ablations, randomization where useful |
| Measurement/construct mismatch | Proxy differs from intended outcome | Operationalize/calibrate and cross-check measurement |
| Base-rate neglect/inverse probability | Likelihood treated as posterior | State reference population, prior and alternative likelihoods |
| Multiple comparisons/optional stopping | Search many metrics for a winner | Freeze confirmation/stopping; adjust or label exploration |
| Leakage | Holdout informs development | Separate/version datasets and inspect contamination |
| Correlated judgment | Agents share evidence/prompts/failure modes | Declare dependencies; use independent methods and measurements |
| Automation/Goodhart effects | Tool score substitutes for correctness | Examine failures, intended utility and integrity tests |
| Hindsight/outcome bias | Criteria rewritten after results | Preserve time-bound plans and deviations |
| Sunk costs/status quo | Prior effort/familiarity drives choice | Compare forward costs and benefits against baseline |
| Novelty/analogy appeal | Elegance treated as superiority | Map invariants/disanalogies and test target domain |

Inspect inference separately from claim truth:
- Affirming the consequent: other mechanisms can predict the same result.
- Denying the antecedent: a sufficient cause absent does not exclude others.
- Circularity: a claim cannot provide its own independent evidence.
- Equivocation/category errors: define verified, simulated, novel, intelligent and safe in scope.
- Composition/division: part behavior does not establish system behavior or the reverse.
- False dilemma: preserve plausible alternatives without giving all equal support.
- Correlation to causation: inspect confounders and intervention assumptions.
- Appeal to ignorance: unmeasured/unrecorded is not proven false, true or original.
- Precision fallacy: extra digits, hashes or scores do not establish accuracy or validity.

Repair the inference or gather evidence; a fallacious argument can have a true conclusion for other reasons. Confidence is not calibration evidence.
